# Lab safety and scope

This repository is for authorized, defensive learning using synthetic records.

## Allowed activities

- Analyze the synthetic CSV records included in this repository.
- Use packet captures that are public, explicitly licensed for training, or created by you in a lab you control.
- Test detections against systems and data for which you have explicit authorization.
- Document findings without exposing personal or confidential information.

## Out of scope

- Scanning or testing third-party systems without written authorization.
- Credential attacks, password spraying, brute force, or phishing.
- Denial-of-service, destructive payloads, persistence, or evasion.
- Capturing or publishing real user traffic, credentials, tokens, or personal data.

## Data handling

Use reserved documentation IP ranges in examples. Sanitize hostnames, usernames, MAC addresses, and payloads before publishing evidence. Never commit secrets, private keys, tokens, raw customer logs, or sensitive PCAP files.

## Reporting

Describe what was actually tested. Mark work that has not been run as **NOT RUN**. Distinguish simulated data from observed data and learning exercises from professional experience.
